# Деплой проекта на Amvera

## Дата: 2026-10-11

## Статус: CLI Amvera не установлен

CLI Amvera не установлен в системе и не доступен через pip. Для деплоя проекта на Amvera используйте веб-интерфейс.

---

## Инструкция по деплою через веб-интерфейс

### 1. Подготовка переменных окружения

Настройте следующие переменные окружения в панели Amvera:

| Переменная | Описание | Обязательна | Пример |
|---|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather | ✅ | `1234567890:ABCdefGhIjKlMnOpQrStUvWxYz` |
| `TELEGRAM_CHAT_ID` | ID чата для уведомлений | ✅ | `-1001234567890` |
| `ADMIN_IDS` | ID администраторов через запятую | ✅ | `123456789,987654321` |
| `OVERDUE_DAYS` | Дней до просрочки | ❌ | `3` |
| `REPORT_HOUR` | Час отчёта | ❌ | `9` |
| `REPORT_MINUTE` | Минута отчёта | ❌ | `0` |
| `REPORT_TIMEZONE` | Часовой пояс (IANA) | ❌ | `Europe/Moscow` |
| `DB_PATH` | Путь к БД | ❌ | `/data/bot.db` |

### 2. Деплой через веб-интерфейс Amvera

1. **Зайдите на [amvera.ru](https://amvera.ru)**
2. **Войдите в аккаунт** или зарегистрируйтесь
3. **Создайте новый проект:**
   - Нажмите «Создать проект»
   - Выберите тип проекта: «Приложение»
4. **Свяжите с GitHub:**
   - Выберите «GitHub» как источник кода
   - Авторизуйте доступ к репозиторию
   - Выберите репозиторий: `MaxAcrata/Telegram_bot`
   - Выберите ветку: `ver2`
5. **Настройте конфигурацию:**
   - Конфигурационный файл: `amvera.yaml`
   - Проверьте, что конфигурация корректна
6. **Добавьте переменные окружения:**
   - Перейдите в раздел «Переменные окружения»
   - Добавьте все обязательные переменные из таблицы выше
7. **Запустите деплой:**
   - Нажмите «Задеплоить» или «Deploy»
   - Дождитесь завершения сборки и деплоя

### 3. Проверка деплоя

После завершения деплоя:

1. **Проверьте логи:**
   - В панели Amvera перейдите в раздел «Логи»
   - Убедитесь, что нет ошибок
   - Должны быть видны сообщения:
     ```
     [INFO] БД инициализирована: /data/bot.db
     [INFO] Бот запущен. Отчёт ежедневно в 09:00
     [INFO] Application started
     ```

2. **Проверьте бота в Telegram:**
   - Откройте Telegram
   - Найдите вашего бота
   - Отправьте `/start`
   - Убедитесь, что бот отвечает

3. **Проверьте основные функции:**
   - Нажмите «➕ Добавить заявку»
   - Проверьте создание заявки
   - Проверьте кнопки «📊 Анализ» и «📊 Дашборд»

### 4. Важные замечания

- **Persistent storage**: БД будет храниться в `/data/bot.db` (volume монтируется в `/data`)
- **Python версия**: Используется Python 3.10 (как указано в amvera.yaml)
- **Автозапуск**: Бот автоматически запускается при старте контейнера
- **Логи**: Доступны в панели Amvera
- **Резервные копии**: Автоматически создаются в `/data/backups`

### 5. Текущая конфигурация amvera.yaml

```yaml
meta:
  environment: python
  toolchain:
    name: pip
    version: "3.10"

run:
  scriptName: bot.py
  persistenceMount: /data
```

## Установка CLI Amvera (опционально)

Если вы хотите использовать CLI Amvera для автоматизации деплоя:

### Вариант 1: Через npm (если доступен)
```bash
npm install -g amvera-cli
```

### Вариант 2: Через curl (Linux/Mac)
```bash
curl -fsSL https://amvera.ru/install.sh | sh
```

### Вариант 3: Через PowerShell (Windows)
```powershell
iex (New-Object Net.WebClient).DownloadString('https://amvera.ru/install.ps1')
```

### Вариант 4: Скачать бинарник
1. Перейдите на [amvera.ru/cli](https://amvera.ru/cli)
2. Скачайте версию для Windows
3. Добавьте в PATH

## Автоматизация через GitHub Actions (опционально)

Для автоматического деплоя при push в ветку `ver2` можно создать GitHub Actions workflow:

```yaml
# .github/workflows/deploy-amvera.yml
name: Deploy to Amvera

on:
  push:
    branches:
      - ver2

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Deploy to Amvera
        run: |
          # Команды деплоя через CLI Amvera
          # или API запросы
```
