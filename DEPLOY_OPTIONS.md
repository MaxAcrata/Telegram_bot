# Варианты деплоя Telegram-бота

## Дата: 2026-10-11

## Обзор

Telegram-бот на Python можно задеплоить на множество платформ. Рассмотрим основные варианты.

---

## 1. Бесплатные платформы

### Railway
- **Сайт:** [railway.app](https://railway.app)
- **Бесплатный план:** 500 часов/месяц, $5 кредитов
- **Преимущества:**
  - Простой деплой из GitHub
  - Автоматические деплои при push
  - Поддержка переменных окружения
  - Persistent storage для БД
- **Недостатки:**
  - Ограниченные ресурсы на бесплатном плане
  - Может спать при неактивности
- **Деплой:**
  1. Зайдите на railway.app
  2. Подключите GitHub
  3. Выберите репозиторий `MaxAcrata/Telegram_bot`
  4. Выберите ветку `ver2`
  5. Добавьте переменные окружения
  6. Запустите деплой

### Render
- **Сайт:** [render.com](https://render.com)
- **Бесплатный план:** 750 часов/месяц
- **Преимущества:**
  - Простой интерфейс
  - Автоматические деплои
  - Поддержка Python
  - Бесплатный SSL
- **Недостатки:**
  - Ограниченные ресурсы
  - Может спать при неактивности
- **Деплой:**
  1. Зайдите на render.com
  2. Создайте новый Web Service
  3. Подключите GitHub репозиторий
  4. Укажите команду запуска: `python bot.py`
  5. Добавьте переменные окружения
  6. Запустите деплой

### Fly.io
- **Сайт:** [fly.io](https://fly.io)
- **Бесплатный план:** 3 shared-cpu VMs, 256MB RAM каждый
- **Преимущества:**
  - Быстрый деплой
  - Глобальная сеть
  - Persistent storage
  - Хорошая документация
- **Недостатки:**
  - Требует信用卡 для регистрации
  - Сложнее в настройке
- **Деплой:**
  1. Установите Flyctl: `curl -L https://fly.io/install.sh | sh`
  2. Войдите: `fly auth login`
  3. Запустите: `fly launch`
  4. Настройте `fly.toml`
  5. Задеплойте: `fly deploy`

### PythonAnywhere
- **Сайт:** [pythonanywhere.com](https://www.pythonanywhere.com)
- **Бесплатный план:** Один Python-проект
- **Преимущества:**
  - Специализация на Python
  - Простой интерфейс
  - Встроенный планировщик задач
  - Бесплатный субдомен
- **Недостатки:**
  - Ограниченные ресурсы
  - Нет persistent storage на бесплатном плане
  - Огранишенный интернет-доступ
- **Деплой:**
  1. Зарегистрируйтесь на pythonanywhere.com
  2. Загрузите файлы через Files tab
  3. Настройте виртуальное окружение
  4. Настройте задачу в Tasks tab
  5. Запустите бота

### Heroku
- **Сайт:** [heroku.com](https://www.heroku.com)
- **Бесплатный план:** Упразднен в 2022 году
- **Альтернатива:** Heroku предлагаает платные планы от $7/месяц
- **Преимущества:**
  - Хорошая документация
  - Множество аддонов
  - Простой деплой
- **Недостатки:**
  - Нет бесплатного плана
  - Дорогие ресурсы

## 6. Быстрый старт с Railway

### Шаг1: Регистрация
1. Зайдите на [railway.app](https://railway.app)
2. Войдите через GitHub

### Шаг2: Создание проекта
1. Нажмите «New Project»
2. Выберите «Deploy from GitHub repo»
3. Выберите `MaxAcrata/Telegram_bot`
4. Выберите ветку `ver2`

### Шаг3: Настройка переменных
1. Перейдите в раздел «Variables»
2. Добавьте переменные:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `ADMIN_IDS`
   - `OVERDUE_DAYS=3`
   - `REPORT_HOUR=9`
   - `REPORT_MINUTE=0`

### Шаг4: Деплой
1. Railway автоматически задеплоит проект
2. Проверьте логи
3. Проверьте бота в Telegram

## 7. Быстрый старт с Render

### Шаг1: Регистрация
1. Зайдите на [render.com](https://render.com)
2. Войдите через GitHub

### Шаг2: Создание сервиса
1. Нажмите «New»
2. Выберите «Web Service»
3. Подключите GitHub репозиторий
4. Выберите `MaxAcrata/Telegram_bot`

### Шаг3: Настройка
1. Имя: `telegram-bot`
2. Среда: `Python`
3. Команда запуска: `python bot.py`
4. План: Free

### Шаг4: Переменные окружения
1. Перейдите в раздел «Environment»
2. Добавьте переменные из таблицы выше

### Шаг5: Деплой
1. Нажмите «Create Web Service»
2. Дождитесь завершения деплоя
3. Проверьте бота в Telegram
